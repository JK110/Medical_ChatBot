# 🏥 Medical ChatBot (RAG + LLM Based)

An AI-powered Medical ChatBot that answers healthcare-related queries using Retrieval Augmented Generation (RAG) and Large Language Models. The chatbot retrieves information from medical documents and generates accurate, context-aware responses.

---

## 🚀 Features

- 📄 Extracts medical knowledge from PDF documents
- 🤖 Uses LLM for intelligent medical query answering
- 🔍 Retrieval Augmented Generation (RAG) pipeline
- 💬 Interactive chatbot interface
- ⚡ Fast and context-aware responses
- 🌐 Web-based UI using Flask
