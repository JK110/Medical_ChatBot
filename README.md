# 🏥 Medical ChatBot (RAG + LLM Based)


## 📌 Project Overview
- AI-powered chatbot designed to answer medical queries.
- Uses Retrieval Augmented Generation (RAG) to provide context-aware responses.
- Extracts knowledge from medical PDF documents.
- Generates intelligent responses using Large Language Models.


---


## 🚀 Features
- 📄 Medical document processing from PDF
- 🤖 AI-based healthcare query answering
- 🔍 Semantic search using vector database
- 💬 Real-time chatbot interaction
- ⚡ Fast and context-aware response generation

## ⚙️ Working Flow
1. Extract text from medical PDF.
2. Convert text into vector embeddings.
3. Store embeddings in Pinecone database.
4. Retrieve relevant medical context.
5. Generate response using LLM.

## 🛠️ Installation


### Clone Repository
```bash
git clone https://github.com/JK110/Medical_ChatBot.git
cd Medical_ChatBot
Create Virtual Environment
python -m venv myenv
myenv\Scripts\activate
Install Dependencies
pip install -r requirements.txt
Add Environment Variables

Create .env file:

PINECONE_API_KEY=your_key
HUGGINGFACE_API_KEY=your_key
Store Embeddings
python store_index.py
Run Application
python app.py
💻 Usage

Open browser

Ask medical questions

Chatbot generates AI-based responses
