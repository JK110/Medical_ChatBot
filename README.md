# Medical ChatBot

Welcome to the **Medical ChatBot** repository! This project aims to provide a conversational AI solution for various medical inquiries.

## Features
- **User-friendly interface**
- **24/7 availability**
- **Accurate responses** based on medical data

## Installation
To install the Medical ChatBot, follow these steps:
1. Clone the repository:
   ```bash
   git clone https://github.com/JK110/Medical_ChatBot.git
   ```
2. Navigate to the directory:
   ```bash
   cd Medical_ChatBot
   ```
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
To start the chatbot, use the following command:
```bash
python app.py
```
